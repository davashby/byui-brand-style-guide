# BYU-Idaho Brand Style Guide

Create the requested artifact using the host's available authoring tools and relevant document, presentation, PDF, or image workflow. A request for a file means deliver that file, not only a prompt. For prompt-only requests, return a usable production prompt. If a required capability is unavailable, identify the specific limitation and provide a useful source or handoff without claiming a finished export.

This is a practical guide, not university approval. Current BYU-Idaho sources are authoritative; the supplied Drive synthesis is secondary.

## Efficient workflow

1. Identify output format, audience, channel, and whether the sender represents the university, a department, or an academic society. Use context and sensible assumptions; ask only when missing information materially changes the rules or artifact.
2. Read only relevant references from the table below. For visual work, apply `references/brand-rules.md`. Do not load the entire source index or historical reconciliation for routine tasks.
3. Choose an asset with `references/assets.md`, then look up only its record in `../../assets/catalog.json` for exact paths, sizing, restrictions, and provenance. Paths are relative to the plugin root. Open the layout index only when using a presentation template.
4. Check the relevant live source for current channel limits, campaign authorization, permissions, source conflicts, or an explicit verification request. Batch independent checks and reuse fetched evidence within the task. Do not crawl the whole website for a routine output. If a necessary source is unavailable, identify the unresolved rule and use the dated summary only with that qualification.
5. Create, inspect, and deliver the requested output. Validate the actual saved artifact, including accessibility and editability where applicable. For multiple formats, reuse validated content and styling. Include concise source links and material approval or export limitations.

## Always apply

- Use Brand Blue `#006EB6`, black, white, and the published supporting palette. Keep logo artwork unchanged. Never generate, trace, or approximate an official logo or Viking mark.
- Use approved university or department identity for the actual sender; society artwork must not become a permanent logo. Use current myBYUI Groups rules for society member communications.
- Check campaign marks in **every** asset, including slide masters, image footers, and linked banners. Both bundled POTX files contain a **25 YEARS** footer. They are conditional anniversary assets, not universal presentation defaults. Do not use them without confirming current anniversary authorization for the intended use. Obtain an approved current generic template when necessary; do not crop/rebuild a restricted mark to manufacture one.
- Check font availability before layout. Do not silently substitute for required Acumin/Minion. Use licensed fonts and report any unresolved substitution.
- Use the official original PNG logo tiles for Office and PDF workflows; preserve their backgrounds, proportions, and clear space. The original supplied WebP tiles remain available for compatible workflows. These files are not transparent/vector masters.
- Produce readable text, meaningful links, image descriptions, appropriate reading order, and contrast. Verify requested charts/tables remain editable in the saved file. Brand alignment does not establish copyright clearance or publishing approval.

For reviews, give observed issues, the supporting source, and the smallest concrete fix. For production, return the artifact and a short account of material limitations; avoid a long compliance recital when no issue requires attention.
