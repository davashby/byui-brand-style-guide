# Asset selection

All paths in `assets/catalog.json` and `assets/powerpoint-layouts.json` are relative to the plugin root, two directories above the skill directory. Use the catalog's exact path, provenance, hash, format, campaign restriction, and sizing metadata. It is an asset inventory, not a claim of university approval for every future use.

## Bundled logos

Prefer the four unmodified original PNGs in `assets/logos/`, downloaded from source URLs exposed by the official logo page on 2026-10-19. They support Office insertion and larger raster output than the 800 × 800 supplied WebP copies. PNG is still raster; no vector or transparent master is bundled. The WebPs are retained as supplied. Backgrounds must stay intact; never crop to the estimated catalog mark bounds.

For exact-color commercial printing, large formats, embroidery, transparent overlays, department marks, or partner arrangements, use the applicable approved source package and review process. [Official Logo](https://www.byui.edu/branding/logos/official), [Department Logos](https://www.byui.edu/branding/logos/department)

## PowerPoint

Both blue and white POTX files remain unchanged from the supplied originals. They contain 25 YEARS anniversary artwork in an EMF master footer. Do not treat them as evergreen templates. Confirm current anniversary authorization and intended use before selecting either. The official public page does not state an exact anniversary end date; do not infer one.

The compact layout index provides slide size, layout names/placeholders, and source hashes. Inspect only layouts needed for the task, then follow the presentation recipe. The working-copy helper preserves native source parts; downstream editing/export can still lose fidelity and must be checked.

For a current generic university deck, use the [PowerPoint resource](https://www.byui.edu/branding/office-templates) and its authenticated SharePoint library. Latest library revisions were not verified in this package. An unavailable generic approved template is an explicit dependency, not permission to manufacture an official template.

## Email signature

[Supplied 2025 signature DOCX](../../../assets/templates/email-signature/BrandedEmailSignatureTemplate-2025.docx): one page with identity/contact placeholders, a university logo, and PC/Mac/Apple Mail setup links. Replace user fields only, preserving branding. This is not a generic document template. Check the [official resource](https://www.byui.edu/branding/office-templates) for the latest signature and setup directions. A rendered DOCX check does not verify Outlook behavior.
